Things to know

Three implementation facts materially qualify platform and integration assumptions.

  • Portal transition

    Microsoft Sentinel support in the Azure portal is scheduled to end after March 31, 2027, with customers redirected to the Microsoft Defender portal.

  • Connector scope

    The Azure Arc multicloud connector lists GCP support as preview and is unavailable in national clouds, so multicloud overlay parity should not be assumed.

  • Integration latency

    The documented Defender for Cloud–ServiceNow integration synchronizes every 24 hours; it should not be treated as the urgent containment path.
