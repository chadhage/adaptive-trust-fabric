# Adaptive Trust Fabric deliverables

Version 1.0 - research cutoff 17 November 2026.

## Start here

- **Microsite:** open `adaptive-trust-fabric-microsite/index.html` in a modern browser. It is self-contained for offline use; no server or external JavaScript library is required.
- **Position paper (PDF):** open `position-paper/Adaptive-Trust-Fabric-Position-Paper.pdf`.
- **Position paper (HTML):** open `position-paper/position-paper.html`.
- **Machine-readable evidence:** use `adaptive-trust-fabric-microsite/data/research.json`.

## Package contents

- `index.html` - interactive decision microsite
- `assets/styles.css` - responsive visual design
- `assets/app.js` - topology assessment, filters and evidence explorer
- `data/research.json` - 33 opened sources, 18 evidence-backed claims, 26 normative controls, survivability tiers, topology patterns, adversarial tests and roadmap
- `position-paper.html` and `paper.css` - printable source for the paper
- `Adaptive-Trust-Fabric-Position-Paper.pdf` - 14-page verified A4 paper
