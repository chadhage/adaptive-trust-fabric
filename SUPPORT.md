# Support

## Community support

This repository contains architecture analysis, proposed control requirements, source records and a browser-based topology assessor. It is provided "AS IS", without warranty of any kind, under the [MIT License](./LICENSE).

For content corrections, broken links, accessibility issues or questions about the material, [open a GitHub issue](https://github.com/chadhage/adaptive-trust-fabric/issues). Include the affected page or file, the expected and actual behavior, and relevant source identifiers. For display or interaction problems, include your browser and operating system.

Do not post credentials, sensitive configurations, personal data or confidential organizational information in an issue.

## Security vulnerabilities

Do not disclose security vulnerabilities in public issues. Follow the [security reporting policy](./SECURITY.md) to report them privately to the Microsoft Security Response Center.

## Support boundaries

This repository is not an official Microsoft product commitment. It does not provide a service-level agreement or support entitlement under a Microsoft support program.

For help with Microsoft products or services, use your existing product-support channel or [Microsoft Support](https://support.microsoft.com/). Product support is separate from community discussion of this architecture.

Validate legal, regulatory, safety, licensing, preview, service-limit, cloud and regional requirements before implementing the guidance.
